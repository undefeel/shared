# 02-03 Ограничить таблицу обнаруженных устройств

## Target
Проект sharedir: двусторонняя синхронизация одной папки между macOS и Linux. Go-демон (`cmd/sharedir`, `internal/*`), меню-бар macOS на SwiftUI (`macos/SharedirBar`), виджет Omarchy на QML (`omarchy/sharedir`). Обнаружение — UDP-броадкаст (22101), передача — HTTP поверх взаимного TLS 1.3 (22100), ID устройства = SHA-256 сертификата, подключаться может только сопряжённое устройство. Есть relay через свой VPS (`internal/relay`). Подробности — `README.md`, отчёты ревью — `plan/reviews/`.

Обнаружение устройств: `internal/discovery/discovery.go`, тесты `internal/discovery/discovery_test.go`. Находка 01-01-03 из `plan/reviews/01-01.md` (часть про UDP; таблицу отклонённых TLS-устройств в `internal/app/daemon.go` делает другая задача — этот файл не трогай).

## Change
Сейчас `recvLoop` записывает каждый валидный ID из UDP-анонса в `devices`, а истёкшие записи (TTL 90 с) никогда не удаляются — только фильтруются при `Lookup`/`Devices`.
1. Удаляй истёкшие записи: при вставке и/или периодически (без отдельной вечной горутины, если можно обойтись очисткой при вставке).
2. Ограничь размер таблицы константой (например, 256). При переполнении сначала выбрасываются истёкшие, затем самая старая по времени последнего анонса. Уже известная запись обновляется, а не добавляется заново.
3. Ограничь частоту обработки анонсов: глобально и на один IP-адрес источника (простой token bucket или окно в секунду). Лишние пакеты молча отбрасываются. Ответ на Ask также подпадает под лимит.

## Constraints
- Приёмка шире пакета: `go vet ./...` и `go test -race ./...` по всему проекту, плюс `make build`.
- Меняешь лимит, таймаут или правило — найди grep'ом все упоминания в `README.md` и комментариях и обнови.
- Проверка в тестах не строже условия: правильное альтернативное решение (другое имя функции, другой порядок проверок) должно проходить.
- Перечисли в комментарии к PR-коммиту все конкурирующие пути, которые учтены. Блокировки — на сущность, а не глобальные. Временная ошибка не должна удалять данные.
- Коммить в свою ветку; сообщение коммита начинай с ID задачи.
- Публичный API пакета (`Lookup`, `Devices` и т. д.) не меняй — его вызывает `internal/app/daemon.go`.
- Тесты: 10 000 анонсов с разными ID → размер таблицы не больше лимита; истёкшие записи удаляются; повторный анонс того же ID не увеличивает таблицу; лимит частоты на один IP. Время в тестах — через подменяемую функцию `now`, без `time.Sleep` на секунды.
