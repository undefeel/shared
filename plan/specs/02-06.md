# 02-06 Экранирование в файлах автозапуска и гонка в activity.go

## Target
Проект sharedir: двусторонняя синхронизация одной папки между macOS и Linux. Go-демон (`cmd/sharedir`, `internal/*`), меню-бар macOS на SwiftUI (`macos/SharedirBar`), виджет Omarchy на QML (`omarchy/sharedir`). Обнаружение — UDP-броадкаст (22101), передача — HTTP поверх взаимного TLS 1.3 (22100), ID устройства = SHA-256 сертификата, подключаться может только сопряжённое устройство. Есть relay через свой VPS (`internal/relay`). Подробности — `README.md`, отчёты ревью — `plan/reviews/`.

Две независимые локальные правки уровня L1.

## Change
1. **01-03-02 — `internal/app/service.go`.** Файлы автозапуска собираются через `fmt.Sprintf` без экранирования.
   - LaunchAgent plist (около строк 57–79): значения `exe` и `home` перед вставкой в `<string>` экранируй через `xml.EscapeText` из стандартного `encoding/xml` (напиши маленькую функцию `xmlEscape(s string) string`).
   - systemd unit (около строк 89–110): путь в `ExecStart=` и значение в `Environment=` оборачивай в двойные кавычки, внутри экранируя `\` → `\\`, `"` → `\"`, `%` → `%%`. Если путь содержит перевод строки (`\n` или `\r`) — функция установки возвращает ошибку «путь содержит перевод строки».
2. **01-02-12 — `internal/app/activity.go`.** `flush` (около строк 65–73) копирует указатели `*Day` под `mu`, а `json.Marshal` идёт уже без него, пока `add` меняет те же объекты. Исправление: под `mu` копируй значения (`d := *day`, новый срез/map значений), маршаль копию. Флаг `dirty` сбрасывай только после успешной записи файла; при ошибке записи верни `dirty = true`.

## Constraints
- Других файлов не меняй.
- Добавь тесты:
  - `internal/app/service_test.go`: генерация plist для пути с `&` и `<` даёт валидный XML (`xml.Unmarshal` без ошибки, значение после разбора равно исходному пути); unit для пути с пробелом содержит `ExecStart="/путь с пробелом/sharedir" run`; путь с `\n` → ошибка. Если генерация сейчас внутри функции установки, вынеси сборку текста в отдельные функции `launchdPlist(exe, home string) string` и `systemdUnit(exe, home string) (string, error)`, а установку оставь вызывать их.
  - `internal/app/activity_test.go`: 10 горутин вызывают `add` и параллельно `flush` в `t.TempDir()` → `go test -race` чистый.
- Коммить в свою ветку, сообщение начинается с `02-06`.
