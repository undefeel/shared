## Change
Implement row 04-54 of the table «Задачи реализации» in `plan/design/perf.md`, section «Пороги приёмки R20», with thresholds recomputed by owner decision item 1 (one F_FULLFSYNC per device per group phase).
- Two real in-process app.Daemon with mTLS HTTP/2 loopback, temp state/root, 2092 deterministic unique files of 11 KiB, depth up to 4, concurrency 6; real flush counters through the per-Folder PersistenceProbe (04-15: SetPersistenceProbe before concurrent use, PersistenceStats). - Assert: index bytes written by the receiver ≤ 4 MiB; repeated no-op Scan writes 0 bytes and 0 flushes; bytes(4000) ≤ 2.3 × bytes(2000) + 256 KiB (no O(N²)); FULLFSYNC count ≤ 3G + 12 with G = number of groups; average group size ≥ 32 with a ready queue.
