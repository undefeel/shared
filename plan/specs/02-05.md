# 02-05 Приватный каталог для control-сокета

## Target
Проект sharedir: двусторонняя синхронизация одной папки между macOS и Linux. Go-демон (`cmd/sharedir`, `internal/*`), меню-бар macOS на SwiftUI (`macos/SharedirBar`), виджет Omarchy на QML (`omarchy/sharedir`). Обнаружение — UDP-броадкаст (22101), передача — HTTP поверх взаимного TLS 1.3 (22100), ID устройства = SHA-256 сертификата, подключаться может только сопряжённое устройство. Есть relay через свой VPS (`internal/relay`). Подробности — `README.md`, отчёты ревью — `plan/reviews/`.

Control-сокет демона: путь вычисляет `internal/config/config.go` (`SocketPath`), слушает `internal/app/control.go` (`listenControl`), клиент Go — в `internal/app/control.go`, клиент macOS — `macos/SharedirBar/ControlClient.swift` (`SharedirPaths.socket` дублирует логику пути). Находка 01-03-01 из `plan/reviews/01-03.md` и дополнение в `plan/reviews/SUMMARY.md`.

## Change
Сейчас, если `home/ctl.sock` длиннее 99 байт, сокет кладётся в общий `$TMPDIR/sharedir-<hash>.sock`. Другой пользователь может заранее занять это имя: демон решит, что уже запущен, а CLI и меню-бар будут слать запросы чужому сокету.
1. Длинный путь: сокет кладётся в приватный каталог `$TMPDIR/sharedir-<uid>/` (на Linux предпочтительно `$XDG_RUNTIME_DIR/sharedir/`, если задан). Каталог создаётся с 0700. Если он уже существует — проверь через `Lstat`, что это каталог (не симлинк), владелец — текущий uid, права не шире 0700; иначе ошибка с понятным сообщением, сокет туда не кладётся.
2. `listenControl`: сокет создавать сразу с правильными правами (umask 0077 на время `Listen` или создание в каталоге 0700 — тогда `Chmod` после не критичен). «Уже запущен» — только если на connect отвечает настоящий демон: запрос `GET /status` вернул валидный JSON. Иначе — понятная ошибка, а не тихий выход.
3. Клиенты (Go и Swift) перед подключением проверяют владельца сокета (`Lstat`, uid совпадает с текущим). Swift — через `lstat` и `getuid()`.
4. Swift `SharedirPaths.socket` должен давать тот же путь, что и Go. Добавь в Go-тест таблицу «home → ожидаемый путь» и продублируй её как комментарий над Swift-функцией.

## Constraints
- Приёмка шире пакета: `go vet ./...` и `go test -race ./...` по всему проекту, плюс `make build`.
- Меняешь лимит, таймаут или правило — найди grep'ом все упоминания в `README.md` и комментариях и обнови.
- Проверка в тестах не строже условия: правильное альтернативное решение (другое имя функции, другой порядок проверок) должно проходить.
- Перечисли в комментарии к PR-коммиту все конкурирующие пути, которые учтены. Блокировки — на сущность, а не глобальные. Временная ошибка не должна удалять данные.
- Коммить в свою ветку; сообщение коммита начинай с ID задачи.
- Короткий путь (`home/ctl.sock`, если влезает) не меняется.
- Тесты Go (`internal/config/config_test.go`, `internal/app/control_test.go` — создай): каталог с чужими правами 0777 или симлинк вместо каталога → ошибка; занятый «немой» сокет (слушает, но не отвечает HTTP) → демон не считает его своим; совпадение пути для коротких и длинных home.
- Swift-часть собери: `make app`.
