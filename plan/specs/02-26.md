# 02-26 CLI подтверждения

## Target
Проект sharedir: двусторонняя синхронизация одной папки между macOS и Linux. Go-демон (`cmd/sharedir`, `internal/*`), меню-бар macOS на SwiftUI (`macos/SharedirBar`), виджет Omarchy на QML (`omarchy/sharedir`). Ядро синхронизации — `internal/folder/`. Идёт исправление ядра по проекту `plan/design/folder.md` (прочитай целиком: разделы «Решение владельца», «Решения и инварианты», «Совместимость и миграция», «Конкурирующие пути» обязательны для всех задач). Исходные находки — `plan/reviews/01-02.md`.

Уровень L1. Задача из раздела «Задачи реализации» проекта, блок `### 02-26`:

> Цель: `sharedir folder-confirm --action reset|rebind --token ...`, вывод ошибки blocked в status. Файлы: `cmd/sharedir/main.go`, `cmd/sharedir/folder_confirm_test.go`. Зависимости: 02-24. Тесты: явное действие/token обязательны, неверный token, успешный вызов control, старый status без error. CLI не подтверждает автоматически.

## Change
Реализуй задачу 02-26 точно по блоку выше и по соответствующим разделам «Решения и инварианты» проекта. Зависимости уже влиты в `main`: используй их API, не дублируй. Тесты из блока обязательны — каждый сценарий отдельным тестом.

## Constraints
- Бюджет: до ~300 строк diff и только файлы из Ownership. Если не укладываешься или нужен ещё файл — не расширяй сам: спроси координатора (`orca orchestration ask`) и жди ответа.
- Протокол между устройствами (`/index`, `/file`, формат FileInfo) не меняй. Новых внешних зависимостей не добавляй (`golang.org/x/sys`, `golang.org/x/text` уже есть).
- Архитектуру (Go-демон, JSON-индекс, HTTP поверх mTLS) не меняй. Если проект в чём-то неисполним — спроси координатора, не импровизируй.
- Коммить в свою ветку, сообщение коммита начинается с ID задачи.
- Образец: существующие подкоманды в `cmd/sharedir/main.go` (разбор флагов, вызов `Ctl`, вывод ошибок) — делай так же.
